# EcoPulse Application and Website — UI/UX Design

EcoPulse is a UI/UX design project for an environmental-awareness mobile application and responsive website. The project connects user needs, information architecture, interaction planning and a consistent visual experience across mobile and desktop screens.

## Design work

- Defined the platform concept, audience and user needs.
- Developed a mobile application interface and responsive website screens.
- Applied usability, visual hierarchy and responsive design principles.
- Documented the design strategy in a detailed case study and presentation.
