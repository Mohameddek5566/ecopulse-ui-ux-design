# EcoPulse Environmental Platform — HCI Case Study

EcoPulse is an environmental awareness campaign platform designed as a complete Human-Computer Interaction case study. The project connects user needs, interaction planning and responsive interface design.

## Design work

- Defined the platform concept, audience and user needs.
- Developed desktop and mobile interface designs.
- Applied usability, visual hierarchy and responsive design principles.
- Documented the design strategy in a detailed case study and presentation.
